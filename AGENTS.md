# Agents Guide

Инструкции и правила для работы с проектом находятся в директории [AI/](AI/README.md).

## Три главных правила
1. **Карточки и ветки**: Все изменения через задачи в `AI/tasks/` и ветки `feat/...`. Прямой push в `main`/`dev` запрещен.
2. **Безопасность и данные**: Запросы к данным магазина фильтруются по `storeId`, входные данные проверяются через Zod, права проверяются на сервере.
3. **Проверка**: Перед сдачей задачи обязательно выполняются линтинг, проверка типов и сборка (`scripts/validate.sh`).
