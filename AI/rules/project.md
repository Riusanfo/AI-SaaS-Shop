# Правила проекта

## Продукт
Облачная платформа для создания и ведения интернет-магазинов без навыков программирования. Внутри встроен ИИ-помощник (генерация описаний товаров, SEO-тексты, структура магазина, ценообразование).

## Стек (Утверждённый)
- **Клиент**: Vite + React + TypeScript (`client/`)
- **Стили**: CSS Modules (по дизайн-токенам и скриншотам из Figma)
- **Общие схемы**: Zod (`shared/`)
- **База данных и миграции**: PostgreSQL + Prisma
- **Контроль качества**: ESLint, строгий TypeScript, Vitest
- **Инфраструктура**: Docker Compose (только для локального PostgreSQL)

## Открытые вопросы (ОТКРЫТО)
- **Сервер**: выбор между Express и Hono — ОТКРЫТО.
- **Хостинг / Деплой**: платформа пока не выбрана — ОТКРЫТО.
- **ИИ-провайдер**: выбор между Gemini и Claude — ОТКРЫТО (сейчас заглушка для тестов).
- **SSR для витрин**: нужен ли серверный рендеринг для SEO — ОТКРЫТО.

## Критерии приёмки
- Создание и публикация магазина за ≤ 60 минут.
- ИИ корректно обрабатывает ≥ 90% типовых запросов.
- Нагрузка: 500 одновременных пользователей при отклике ≤ 2 с.
- Интеграции: ≥ 2 платёжных сервиса (sandbox) и 1 служба доставки (sandbox).
- Роли: `PLATFORM_ADMIN`, `STORE_OWNER`, `STORE_MANAGER`, `BUYER`.
