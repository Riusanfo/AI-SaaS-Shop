# Правила проекта и архитектурный стек

## Продукт
Облачная платформа для создания и ведения интернет-магазинов без навыков программирования. Внутри встроен ИИ-помощник (генерация описаний товаров, SEO-тексты, структура магазина, рекомендации по ценообразованию).

## Утвержденный стек (Фактическое состояние)
- Клиент: Vite + React 19 + TypeScript в директории `src/`.
- Сервер: Node.js + Express 4 + TypeScript в директории `server/`.
- База данных: Облачная PostgreSQL в Neon Serverless (регион Франкфурт `eu-central-1`) + Prisma ORM (миграции через `prisma migrate`).
- Стили: CSS Modules по дизайн-токенам (палитра Warm Editorial & Honey Amber в `AI/design/tokens.md`).
- Валидация: Zod-схемы на каждом эндпоинте бэкенда (`server/src/schemas/`).
- Аутентификация: сессии в таблице БД `sessions`, защищенные куки `HttpOnly` (`shop_session_id`, 7 дней, SameSite=Lax), нативный `scrypt` для хеширования паролей.
- Контроль качества: ESLint, строгий TypeScript, валидационный скрипт `scripts/validate.sh`.
- Инфраструктура: Docker Compose (`docker-compose.dev.yml`) исключительно как резервная локальная копия PostgreSQL для работы без интернета.

## Открытые вопросы (Требуют решения на этапе генератора)
- ИИ-провайдер в продукте: выбор между Gemini и Claude (сейчас ИИ-вызовы работают через интерфейс-заглушку).
- Платформа финального деплоя: выбор облачного PaaS/VPS для сервера и витрин.
- Необходимость SSR для витрин покупателей: SPA или Server-Side Rendering для индексации поисковиками.

## Критерии приемки проекта (по ТЗ)
- Создание и публикация магазина за <= 60 минут.
- ИИ корректно обрабатывает >= 90% типовых запросов.
- Нагрузка: 500 одновременных пользователей при отклике <= 2 с.
- Интеграции: >= 2 платежных сервиса (ЮKassa, CloudPayments в sandbox) и 1 служба доставки (СДЭК в sandbox).
- Роли: `PLATFORM_ADMIN`, `STORE_OWNER`, `STORE_MANAGER`, `BUYER`.
