# Дизайн-токены: Тёплый редакционный стиль (Warm Editorial & Honey Amber)

## Цветовая палитра (Light / Dark)

### Светлая тема (Oat & Linen / Овсяное молоко и лён)
- Фоновый холст (`--bg-canvas`): `#F7F4EE` (тёплый оттенок небелёного льна)
- Поверхность карточек (`--bg-surface`): `#FFFDF9` (тёплый маслянистый белый)
- Вторичный фон / инпуты (`--bg-subtle`): `#EFEAE1` (песочно-кремовый)
- Фон шапки (`--bg-header`): `rgba(247, 244, 238, 0.9)`
- Основной текст (`--text-primary`): `#221F1B` (тёплый тёмный эспрессо)
- Вторичный текст (`--text-muted`): `#7D7569` (тёплый серо-коричневый)
- Границы (`--border`): `#E2DCD2` (мягкий контур льняной бумаги)
- Границы акцентные / разделители (`--border-subtle`): `rgba(34, 31, 27, 0.06)`
- Акцент / Действие (`--accent`): `#C87A24` (янтарный мёд / тёплая карамель)
- Текст на акценте (`--accent-contrast`): `#FFFFFF`
- Статусный акцент (`--accent-status`): `#2D6A4F` (лесной шалфей)
- Фон бейджей (`--badge-bg`): `#EFEAE1`
- Тени карточек (`--card-shadow`): `0 8px 24px rgba(34, 31, 27, 0.05)`

### Тёмная тема (Charred Oak & Dark Chocolate / Обожжённый дуб)
- Фоновый холст (`--bg-canvas`): `#181614` (тёплый кофейно-черный)
- Поверхность карточек (`--bg-surface`): `#201D1A` (бархатный тёмный шоколад)
- Вторичный фон / инпуты (`--bg-subtle`): `#282420` (тёплая кофейная подложка)
- Фон шапки (`--bg-header`): `rgba(24, 22, 20, 0.9)`
- Основной текст (`--text-primary`): `#F6F2EB` (сливочный белый / античная слоновая кость)
- Вторичный текст (`--text-muted`): `#A39B8F` (сепия / тёплый пепел)
- Границы (`--border`): `rgba(246, 242, 235, 0.12)`
- Границы акцентные / разделители (`--border-subtle`): `rgba(246, 242, 235, 0.06)`
- Акцент / Действие (`--accent`): `#E08B34` (светящийся янтарный мёд)
- Текст на акценте (`--accent-contrast`): `#181614`
- Статусный акцент (`--accent-status`): `#34D399`
- Фон бейджей (`--badge-bg`): `rgba(246, 242, 235, 0.06)`
- Тени карточек (`--card-shadow`): `0 16px 36px rgba(0, 0, 0, 0.45)`

## Скругления (Мягкие и дружелюбные iOS/macOS)
- Кнопки, инпуты, бейджи: `10px`
- Карточки, модалки, дроверы: `14px`
- Пилюли-теги: `20px`

## Типографика и сетка
- Основной шрифт: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- Моноширинный: `'JetBrains Mono', ui-monospace, Consolas, monospace`
- Границы: строго `1px solid var(--border)`
