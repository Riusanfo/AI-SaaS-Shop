# Руководство по разработке: React & TypeScript

## Архитектура и компонентный подход
1. **Строгая модульность**: Каждый React-компонент находится в собственной директории `src/components/ComponentName/` и содержит:
   - `ComponentName.tsx` — логика и разметка компонента.
   - `ComponentName.module.css` — стили (CSS Modules), исключающие глобальные конфликты.
2. **Запрет монолитов**: Запрещено складывать всю логику или стили в `App.tsx` или `App.css`. `App.tsx` служит исключительно корневым контейнером компоновки.
3. **Чистый React**: Не используются сторонние CSS-фреймворки (Tailwind и др.). Все стили пишутся на чистом CSS / CSS Modules с использованием переменных.

## TypeScript стандарты
- Строгий режим (`strict: true`).
- Запрет использования типа `any`. Для всех пропсов и состояний создаются явные интерфейсы (`interface` или `type`).
- Валидация внешних данных через **Zod** (схемы в `shared/`).

## Управление состоянием и эффектами
- Состояние компонентов поднимается только при необходимости совместного использования.
- Использование `useEffect` строго для синхронизации с внешними системами. Всегда возвращать функцию очистки (cleanup), если эффект подписывается на события или таймеры.
