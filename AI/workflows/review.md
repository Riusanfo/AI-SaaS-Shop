# Чек-лист ревьюера (PASS / FAIL)

Каждое ревью завершается вердиктом **PASS** или **FAIL**.

## Критерии проверки
1. **Изоляция данных (`storeId`)**: Все запросы к данным магазина обязательно фильтруются по `storeId`.
2. **Безопасность и права**: Права проверяются на сервере (`requireRole`), входные данные валидируются через Zod.
3. **Чистота кодовой базы**: Нет `any`, лишних зависимостей, мертвого кода, неиспользуемых абстракций (YAGNI).
4. **Тесты и сборка**: Скрипт `scripts/validate.sh` завершается успешно без ошибок.
5. **Объем дифа**: Изменены только файлы, относящиеся к задаче.
