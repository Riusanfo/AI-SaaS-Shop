# Воркфлоу задачи

Цикл работы над любой задачей в проекте:
1. **Карточка**: Создание файла задачи в `AI/tasks/` на основе шаблона `_TEMPLATE.md`.
2. **План**: Короткий пересказ задачи и план из 3–5 шагов. Одобрение человеком.
3. **Реализация**: Написание минимального рабочего кода в ветке `feat/...`. Изменения только в файлах задачи.
4. **Проверка**: Локальный запуск `validate.sh` (lint, typecheck, build).
5. **Ревью**: Проверка по чек-листу (`AI/workflows/review.md`).
6. **PR / Merge**: Создание Pull Request в основную ветку.
