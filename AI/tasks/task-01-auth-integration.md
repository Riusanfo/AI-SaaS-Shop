# Карточка задачи: Интеграция авторизации фронтенда с бэкендом

## Описание задачи
- **Что сделать**: Заменить mock-сервис авторизации на клиенте на реальные вызовы эндпоинтов Express API (`/api/auth/*`) с использованием сессионных cookie (HttpOnly), настроить прокси в Vite и убрать сохранение профиля в `localStorage`.
- **Цель**: Обеспечить сквозную аутентификацию с реальной валидацией данных в БД Neon PostgreSQL и корректное разграничение доступа по ролям (`STORE_OWNER` vs `BUYER`). Соответствует критериям безопасности и ТЗ.

## План реализации
1. Настроить proxy для `/api` на `http://localhost:3001` в `vite.config.ts`.
2. Реализовать `authService.ts` с методами `signUp`, `signIn`, `signOut`, `getMe` через нативный `fetch` с `credentials: 'include'`.
3. Модернизировать `AuthContext.tsx`: загрузка профиля через `getMe()` при старте приложения, управление состоянием `isLoading`, удаление ненадежного сохранения `User` в `localStorage`.
4. Проверить линтинг (`npm run lint`), сборку (`npm run build`) и сквозной сценарий работы.

## Критерии проверки
- [x] `npm run lint` проходит без ошибок (0 errors).
- [x] `npm run build` собирается успешно (~400 мс).
- [x] Запросы `/api/auth/signup`, `/api/auth/login`, `/api/auth/logout`, `/api/auth/me` корректно настроены на проксирование.
- [x] Сессионная кука сохраняется браузером и передается в запросах (`credentials: 'include'`).
- [x] При обновлении страницы профиль запрашивается с сервера через `/api/auth/me` без мерцания модалок.
