# Карточка задачи: ИИ-генератор структуры и контента магазина за 60 секунд

## Описание задачи
- **Что сделать**: Разработать серверный модуль генерации витрины `POST /api/ai/generate-store`, формирующий валидную блочную конфигурацию магазина и каталог товаров на основе короткого описания ниши от пользователя (One-Shot Onboarding).
- **Цель**: Выполнить ключевые требования ТЗ («создание и публикация магазина за <= 60 минут» и «ИИ корректно обрабатывает >= 90% запросов»), превратив конструктор в полноценный AI-SaaS сервис.

## План реализации
1. Создать серверный сервис `server/src/services/aiGenerator.ts`:
   - Системный промт с жестким контрактом: выбор шаблона (`minimal`, `catalog`, `story`), акцентного цвета, генерация заголовков Hero, текста «О магазине» и 3–4 товаров с реалистичными ценами.
   - Валидация вывода модели через Zod-схему `generatedStoreSchema`.
   - Поддержка fallback-режима (детерминированная заглушка при отсутствии ключа API или сетевых сбоях).
2. Реализовать маршрут `POST /api/ai/generate-store` под защитой `requireAuth` + `requireRole('STORE_OWNER')`.
3. Добавить в интерфейс создания магазина кнопку «Сгенерировать через ИИ» с полем описания идеи (например: «Крафтовое мыло ручной работы с травами и маслами, эко-стиль, средний чек 650 рублей»).
4. Интегрировать результат генерации прямо в состояние конструктора с возможностью сохранения в Neon в один клик.
5. Проверить `npm run lint` и `npm run build`.

## Критерии проверки
- [ ] Серверный эндпоинт отдает строго валидированный по Zod JSON-конфиг витрины.
- [ ] Время генерации ответа не превышает установленный таймаут (до 10 с при реальном API или моментально при fallback).
- [ ] Полученные блоки и товары корректно рендерятся в конструкторе и живом предпросмотре.
- [ ] `npm run lint` и `npm run build` проходят с 0 ошибок.
